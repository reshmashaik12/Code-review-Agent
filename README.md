Code Review Agent

A lightweight web-based code review tool built using Python (Flask) and HTML/CSS, integrated with the ScaleDown API for efficient prompt compression.


🚀 Features

Submit code through a simple web interface

Compress prompts using ScaleDown API

Rule-based code review feedback

Beginner-friendly and cost-efficient

🛠️ Tech Stack

Frontend: HTML, CSS

Backend: Python, Flask

API: ScaleDown (Prompt Compression)

🔮 Future Scope

Multi-language code support

AI-based review system

Code quality scoring
